## Where to play it:  
- Click this link to play the mini games: https://xorphic.itch.io/two-minigames  

- Press start and you are going to start with the catcher game if you loose it will restart and if you win you will go to the next mini game. In the second mini game if you loose you will get the you loose screen and if you win you will have the you won screen.
